# Optional Hyprland session

```bash
./install.sh --hyprland
```

Hyprland is **not** the default. GNOME stays the Ubuntu login session.

If the packages exist on this Ubuntu release, the installer writes:

- `~/.config/hypr/hyprland.conf`
- `~/.config/waybar/` (same palette as Kitty)

Pick **Hyprland** from the login-screen session menu. Super+Return / Super+T launch Kitty.

On a Latitude 5400, prefer GNOME for battery and stability. Hyprland is for people who explicitly want a tiling session.
