# Game / mod development (optional)

```bash
./install.sh --gaming
```

This prepares `~/Projects/games` and may install `lua5.4` / confirm `git-lfs`.

It does **not** install Steam, Godot, Blender, Proton, or Wine. Those are large and not everyone needs them.

Install later if you want them:

```bash
sudo apt-get install godot4 blender   # if this Ubuntu archive has them
```

Steam: Ubuntu Software, or the official .deb from Valve.
