# Workstation palette (one language everywhere)

Deep dark cyber / developer. Not pastel, not rainbow.

| Token | Hex | Use |
|-------|-----|-----|
| bg | `#0b0e14` | terminal / tmux background |
| fg | `#c0caf5` | primary text |
| muted | `#565f89` | suggestions, time, separators |
| cyan | `#7dcfff` | directory, keys, accents |
| blue | `#7aa2f7` | secondary accent, Docker |
| purple | `#bb9af7` | git branch, titles |
| green | `#9ece6a` | success, valid commands |
| red | `#f7768e` | errors, dirty git |
| yellow | `#e0af68` | duration, warnings |
| orange | `#ff9e64` | modified |

Used by: Kitty, Starship, Fastfetch, tmux, fzf, Yazi.
